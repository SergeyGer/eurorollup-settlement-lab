# Compatibility manifest and release identifiers

This page records the exact identifiers used for the `v1.0.0` release: runtimes,
toolchains, model, circuit, chain fork and the pinned container images. The
machine-readable release manifest is generated by `pnpm release:package`
(`MANIFEST.json` inside the downloadable package) and the per-run evidence packs.
